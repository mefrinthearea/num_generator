# Random Number Generator

A browser utility that generates a random integer within a user-supplied inclusive range.

## Features

Minimum and maximum inputs, click-driven generation and result display using Math.random and Math.floor.

## Technology

HTML, CSS and vanilla JavaScript.

## Getting started

```sh
git clone https://github.com/mefrinthearea/num_generator.git
cd num_generator
```

Open `num_generator/index.html` in a browser. No package installation or build step is required. External fonts or icons may require an internet connection.

## Entry point

`num_generator/index.html`

## Scope and limitations

Input validation is not implemented. Use integer bounds with minimum less than or equal to maximum. Not intended for cryptographic randomness.
